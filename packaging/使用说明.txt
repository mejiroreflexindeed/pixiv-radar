Pixiv 小说雷达 使用说明（测试版 2026-09-27）
================================================

零、这是什么
-----------
- 本地小工具：把 Pixiv 上某个标签的小说低频、只读地搜出来，按"小众新发现 / 稳定追踪 /
  热门参考 / 待观察"分组，帮你发现值得追的作品；需要时再对个别作品做正文结构分析
  （只显示语言、字数、对话比例、结构规则、相似列表，不显示原文）。
- 所有数据都存在你自己的电脑上（软件文件夹里的 data 目录）。只有你在网页里点击
  "登录 / 运行发现"之后才会访问 Pixiv，而且只做低频只读搜索，不会收藏、关注、
  评论或发布任何内容。
- 这是给朋友测试用的版本，没有代码签名；有问题请截图反馈，不要发送账号信息。

一、运行要求与启动
-----------------
1. 建议 Windows 10 / 11 64 位。把整个文件夹解压到任意可写位置（桌面、文档、U 盘均可）。
   注意：不要只把 exe 单独拷出来，旁边的 _internal 和 .runtime 文件夹必须一起带着。
2. 双击 "Pixiv雷达.exe"。第一次打开可能出现蓝色 SmartScreen 提示（测试版没有签名）：
   点"更多信息"→"仍要运行"。
3. 会出现一个启动面板：
   - 离线演示：不用账号，直接体验全部界面（使用内置演示数据）。
   - 真实模式：点网页里的登录按钮后，会弹出一个浏览器窗口；请在该窗口里用你自己的
     Pixiv 账号完成登录（密码和验证码只在 Pixiv 官方页面输入，本软件不接触、不保存）。
     登录成功后，凭据保存在 Windows"凭据管理器"的一个固定条目里，只有本软件能读取。
4. 选好模式后点"启动"，会自动打开浏览器进入 http://127.0.0.1:8000/
   （仅本机可访问）。之后可随时用面板上的"打开页面"再打开。

二、日常使用（都在浏览器页面里）
-------------------------------
1. 发现：输入标签（默认 ウマ娘）→ 点"运行发现/扫描"。出现候选列表后，点某一行看右侧详情：
   标题、作者、标签、来源和"为什么被推荐"；点外链去 Pixiv 阅读。
2. 我的作品：被追踪的作品表格，可排序、筛选，点行查看历史曲线。
3. 反馈：详情里可以"标记好文 / 标记排除 / 撤销"；刷新页面后仍然保留。
4. 正文分析：作品进入"稳定追踪"后，详情里可以点"分析这篇正文"
   （显示语言、字数、对话比例、结构规则、相似列表）。条件不满足时按钮是灰的，
   隔几分钟多跑几轮扫描，自然会满足。
5. 运行与设置：查看运行历史、调度状态、连接状态与诊断信息。

三、定时自动扫描（可选）
-----------------------
- 在启动面板勾选"定时自动扫描"，填写分钟数（15–1440，建议 30–60）和标签，再点启动。
- 软件开着时就会按间隔自动扫描（第一次要等一个完整周期）；页面上会显示调度信息。
- 关闭软件即停止，不会在后台偷偷运行。

四、数据、备份与卸载
-------------------
- 所有数据都在软件文件夹的 data 目录下：
  - 真实模式数据库：data\state\radar.db（最重要，包含你的追踪与反馈）
  - 离线演示数据库：data\demo\radar.db（可以随时删除，会自动重建）
  - 日志：data\logs\（反馈问题时可以一并打包发来）
- 备份：关闭软件后，把 data\state\radar.db 复制到别处保存即可。
- 卸载：直接删除整个软件文件夹即可；如果想同时清除登录凭据，打开
  "控制面板 → 凭据管理器 → Windows 凭据"，删除 pixiv-radar 条目。

五、停止与安全
-------------
- 停止：在面板上点"停止并退出"，或直接关闭面板窗口。关闭浏览器标签页不影响服务。
- 软件只监听 127.0.0.1（本机回环地址），同一局域网内的其他设备访问不到。
- 你的密码、验证码不会经过本软件；抓取到的正文只保存在本地数据库中。

六、测试朋友请注意（重要）
-------------------------
1. 请使用你自己的 Pixiv 账号，并在 Pixiv 官方页面自行完成登录（可能需要人机验证）。
2. 如果遇到 401 / 403 / 429（请求过多）或验证码挑战：先停止操作，把页面提示截图，
   不要连续重试；稍等一段时间再试。
3. 已知情况（属于正常/已知行为）：
   - 短时间内反复扫描可能触发 Pixiv 限流，这是官方的保护机制。
   - 正文分析需要作品先进入"稳定追踪"，可能需要间隔几分钟多跑几轮。
   - 杀毒软件可能对未签名程序有提示；如不放心可以先不运行。
4. 反馈请附：现象截图 + 发生时间 + 你当时在做什么 + （可选）data\logs 下的日志文件。
   绝对不要发送账号、密码、验证码或任何登录凭据。

版本：登录可用测试版（2026-09-27），本地回环单服务，无云同步、无多账号、无自动发布。

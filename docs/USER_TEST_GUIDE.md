# Pixiv 小说雷达 用户测试指南（登录可用版）

从 GitHub 源码使用时，先按[开发与安装说明](DEVELOPMENT.md)安装依赖并构建前端，
然后双击根目录的 `.cmd` 入口。已分发的 EXE 包按包内说明使用，无需安装 Python/Node。
登录在打开的官方页面由你本人完成，本软件不收集你的账号、密码或验证码。

## 1. 先看离线演示（可选，5 分钟）

1. 双击 `查看离线演示.cmd`，浏览器打开 `http://127.0.0.1:8000`。
2. 页面顶部有黄色“演示数据”横幅和“演示模式”标记，连接状态为不可用——这是正常的。
3. 点击“运行发现/扫描”：第一次显示“部分成功”（一个来源临时失败），再点一次显示“成功”。
4. 点击任意候选行，右侧出现标题、作者、Pixiv 外链、历史曲线和个人反馈。
5. 点“标记好文”“标记排除”“撤销当前反馈”，状态随之更新。
6. 展开“雷达与热力图”，点击图中的点，右侧详情会切换到对应作品。
7. 关闭命令行窗口即可停止。

演示数据与真实数据分开存放，不会混淆。

## 2. 真实模式：登录并发现

1. 双击 `启动 Pixiv 小说雷达.cmd`，浏览器打开 `http://127.0.0.1:8000`。
2. 页面加载不会自动登录、不会自动扫描。连接状态显示“未配置/未连接”。
3. 点击登录，在打开的官方页面里**由你自己**输入账号、密码或验证码；完成后回到雷达页面，
   连接状态变为已连接。
4. 在“发现”视图输入标签（默认ウマ娘），点击“运行发现/扫描”。
   每轮只对同一标签做精确标签、部分标签、关键词三次低频只读搜索，不会收藏、关注、
   评论或发布。结果可能是空、部分成功或成功，以实际为准。
5. 点击候选查看标题、作者、来源和“为何出现”；外链指向相同 novel_id 的 Pixiv 页面。
6. 在“我的作品”视图可用筛选、排序和翻页；点击行或按 Enter/空格选择，右侧显示详情。
7. 对同一标签在相隔至少一分钟的时点重复运行，作品会按真实的 EWMA/动态门限状态机
   从冷启动进入广域或追尾；这不会额外增加接口请求。

## 2.1 定时自动扫描（可选，默认关闭）

如果希望“软件开着，它自己间隔一段时间扫一次”：

1. 在项目目录打开 PowerShell，运行（示例：每 30 分钟扫一次 ウマ娘）：
   `.\backend\.venv\Scripts\python.exe scripts\run_real_app.py --enable-real --schedule-minutes 30 --tag ウマ娘`
2. 或者给 `启动 Pixiv 小说雷达.cmd` 建一个快捷方式（右键 → 新建快捷方式，目标填带参数的路径）：
   `"<仓库绝对路径>\启动 Pixiv 小说雷达.cmd" --schedule-minutes 30 --tag ウマ娘`（把占位路径替换为实际位置）。
3. 间隔范围 15–1440 分钟；首次请求要等一个完整周期；运行中、未连接、共享门暂停或限流冷却时跳过本轮。
4. 启用后页面上会显示调度信息；关闭命令行窗口即停止，不会后台运行。

默认关闭是为了避免频繁请求触发 Pixiv 限流；自动扫描与手动扫描完全相同：同标签三次低频只读搜索，
不会收藏、关注、评论或发布。

## 3. 反馈与正文分析

- “标记好文/排除/撤销”保存在本地；刷新或重启后仍在，并会影响候选排序和解释。
- 只有已经进入 `track` 的作品才能分析正文。选中后点击“分析这篇正文”，只会请求这一篇；
  页面显示语言、段落、对话占比、结构规则、原因码和本地 TF-IDF 相似列表，**不显示正文原文**。
- 再次打开同一作品默认只读本地缓存；点“重新抓取并分析”才会再次请求。
- 结构分、杂波规则和文本相似度都不是文学质量结论，最终取舍由你的反馈决定。

## 4. 备份与恢复（你主动操作）

1. 双击 `备份我的数据.cmd`。它只读正式库，输出到 `data\backups\radar-<时间戳>.db`，
   不会修改、迁移或覆盖原库；备份不含账号登录信息。
2. 恢复时使用显式命令恢复到**不存在的新目录**：

   ```powershell
   # 在仓库根目录运行
   .\backend\.venv\Scripts\python.exe scripts\backup_restore.py restore `
     data\backups\radar-20260909-120000.db data\restored-01
   ```

3. 用新库启动核对（确认无误前不要替换正式库）：

   ```powershell
   .\backend\.venv\Scripts\python.exe scripts\run_real_app.py `
     --enable-real --db-path data\restored-01\radar.db
   ```

## 5. 什么时候立即停止并反馈

出现下列任一情况就停止，不要连续重试：

- 401、403、429 或页面提示冷却；
- 验证码/挑战页面；
- Windows 凭据后端不可用；
- 页面数量与脚本/预期明显不一致；
- 服务监听地址不是 `127.0.0.1`。

反馈时只需说明现象、页面上的受控错误码和大致时间，**绝不要发送 token、密码或验证码**。

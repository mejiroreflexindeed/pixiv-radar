# 当前实施交接（2026-10-22 源码入库整理）

状态：`OFFLINE_VERIFIED / LIVE_PENDING=true`

软件以 2026-09-27 的功能实现为基线。本轮为 GitHub 源码交付整理了目录索引、
安装开发说明、架构与忽略规则，修正就绪检查中的固定盘符提示，并允许新克隆在
首次启动时创建缺失的 `data/`。主要业务与数据格式保持现有实现。

## 功能与源码入口

- 本地 FastAPI + React + SQLite WebUI，仅监听 `127.0.0.1`。
- 受监督浏览器登录与登录复用，密码/验证码由用户在官方页面输入。
- 三次低频标签搜索、候选分组与解释、状态追踪、图表、筛选排序与个人反馈。
- `track` 目标按篇正文轻量分析、缓存与本地 TF-IDF 相似结果；API/UI 不返回原文。
- 只读备份、恢复到新目录，以及默认关闭的进程内定时发现。
- Windows GUI 启动面板和 EXE 打包脚本，见 `scripts/` 与 `packaging/`。
